# 데이터 출처 표시

확인일: 2026-10-19. 현재 예제 지도는 프로젝트가 직접 작성한 합성 fixture만 표시한다. OSM이나 공공기관의 실제 데이터를 쓰는 것처럼 표시하지 않는다. [원장](../data/sources.json)에 등록된 A 후보도 다운로드·번들에 포함되어 있지 않다.

## 표시 원칙

- 지도에서 실제 사용 중인 provider의 표시만 합친다. 기본 MIT 코드 고지와 지도 데이터 출처는 분리한다. 출처 문구는 폰트 크기·대비·화면 안전영역을 확보하며 MapLibre attribution을 숨기지 않는다.
- 데이터명, 실제 제공기관/권리자, 공식 원본 URL, 원본 라이선스/조건, 데이터 기준일, 취득·가공 내역을 데이터 릴리스 manifest에 보관한다. 화면에는 간결한 문구와 상세 출처 화면의 접근 경로를 제공한다.
- Web 링크, Native에서 열 수 있는 링크 및 오프라인 출처 문서를 준비한다. 지도 캡처·인쇄·정적 이미지·오프라인 패키지는 각 원문 조건에 맞게 별도 확인한다. 클릭 링크만 없는 상태로 복사하지 않는다.
- 출처를 표시했다고 저장·수정·재배포 권한이 생기지는 않는다. C/D 데이터를 표시 문구만 붙여 수집하거나 배포하지 않는다.

## 템플릿

| 대상 | 화면 표시 예 | 배포물의 상세 고지 |
| --- | --- | --- |
| 자체 합성 fixture | 합성 테스트 데이터 · Korea Map Kit | MIT / 실제 지도 데이터 아님 |
| OSM 데이터 사용 시 | © OpenStreetMap contributors | [OSM 저작권](https://www.openstreetmap.org/copyright), [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/), 원본·가공·DB 접근 제공 방식 |
| Geofabrik 추출본 사용 시 | OSM 표시 + 필요 시 추출 정보 링크 | Geofabrik, 추출 지역·수록 시각·파일 해시; 별도 Geofabrik 지도 저작물로 오인하지 않음 |
| 개별 제한 없음 공공데이터 | 제공기관 · 데이터명 · 기준일 | 원장에 있는 정확한 원본 URL과 당시 이용허락 표시; 가공/필터링 내역 |
| TourAPI 구조화 정보 사용 시 | 한국관광공사 TourAPI · 정보 기준일 | 승인된 텍스트/위치 속성 범위, 갱신·삭제 반영, 미디어 별도 권리 확인 |
| 추후 공공누리 1유형 확인 데이터 | 제공기관 · 저작물명 · 기준연도 | 실제 공공누리 유형·원문 링크·변경 내용; 기관의 서비스 보증/후원을 암시하지 않음 |

공공데이터의 출처 표시는 프로젝트의 추적 정책도 포함한다. `이용허락범위 제한 없음` 자료를 공공누리 1유형이라고 잘못 표시하지 않는다. 원본의 출처 의무가 더 구체적이면 그 조건을 따른다. 사진은 사진별 권리자·유형 확인이 필요하며, 현재 사진 에셋은 승인되지 않았다.

## QA와 검증 범위

`pnpm check:data`는 각 후보의 비어 있지 않은 출처 문구와 권리 근거를 확인한다. `pnpm check:data-docs`는 원장과 공급원 문서의 일치를 확인한다. 코드의 합성 fixture는 공개 검토 목록의 해시로 보호한다. 이는 실제 화면에서 OSM/기관 출처가 올바르게 노출된다는 QA가 아니다.

외부 provider를 구현할 때 Web/Android/iOS에서 작은 화면, 확대/축소, provider 변경, 오류/오프라인, 지도 캡처 각각의 표시를 실제 검증한다. 현재 실화면은 합성 fixture의 기존 Web 테스트만 가능하며, 외부 데이터 표시와 Native 화면은 미검증이다.
