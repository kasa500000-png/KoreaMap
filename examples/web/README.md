# Web example

Private Next.js consumer of the SDK. Run `pnpm dev:web` from the root.
`pnpm build` exports static files into `examples/web/out`; `pnpm test:web` checks that build.
All geometry is original synthetic fixture data, not a real Korean basemap.
No environment file, API key, remote font, geocoder or backend is required.
This example uses explicit local-fixture configuration. External providers are not implemented.
Production deployment and its hosting limits require separate approval.
